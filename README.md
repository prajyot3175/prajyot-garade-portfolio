# Prajyot Garade Portfolio

Recruiter-focused portfolio for Prajyot Vijay Garade, built with React and Vite.

## Included

- Software engineering and QA/testing resume downloads
- Projects, experience, education, achievements, certifications, and contact links
- Responsive single-page portfolio design

## Run locally

Requires Node.js and pnpm.

    pnpm install
    PORT=5000 BASE_PATH=/ pnpm --filter @workspace/prajyot-portfolio run build
    PORT=5000 BASE_PATH=/ pnpm --filter @workspace/prajyot-portfolio run dev

The portfolio app is located at artifacts/prajyot-portfolio.
